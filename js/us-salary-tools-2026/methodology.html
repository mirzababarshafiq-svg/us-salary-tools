Methodology - Tax Year 2026 Engine v2026.1.0

Last verified: 2026-05-13

Overview

This site uses a single authoritative engine module js/tax-engine/index.js that is the sole source of truth for all calculations. Salary, paycheck, state comparison, hourly converters all call the same functions.

Pipeline Order (§4.1)

  1. Normalize income (hourly/weekly/biweekly/semimonthly/monthly/daily → annual gross)
  2. Sanitize & validate inputs (clamp negative, locale handling, max $1T)
  3. Classify deductions (traditional 401k pretaxFedOnly, Roth post-tax, HSA via payroll pretaxFedFica, health/FSA cafeteria, other pretax)
  4. Calculate taxable wages per base: federal, Social Security, Medicare, state
  5. Calculate federal taxable income = federalTaxableWages - standardDeduction (2026: $16,100 single, $32,200 MFJ, $16,100 MFS, $24,150 HoH) - extra for age65/blind
  6. Federal income tax via 2026 brackets (IRS Rev Proc 2025-32): 10% up to $12,400 single / $24,800 MFJ, 12% to $50,400 / $100,800, 22% to $105,700 / $211,400, 24% to $201,775 / $403,550, 32% to $256,225 / $512,450, 35% to $640,600 / $768,700, 37% above. HoH and MFS per IRS tables.
  7. Withholding realism: Option A implemented - Pub 15-T Percentage Method Automated Payroll Systems. Inputs: filingStatus, multipleJobs checkbox (simplified 5% uplift documented), dependentAmount (Step 3 credit), otherIncome (Step 4a), deductions (Step 4b), extraWithholding (Step 4c). Method disclosed in UI.
  8. FICA: Social Security 6.2% on wages up to $184,500 (SSA 2026) max $11,439, capped per paycheck. Medicare 1.45% no cap. Additional Medicare 0.9% liability thresholds: Single/HoH $200k, MFJ $250k, MFS $125k. Withholding trigger $200k regardless filing status (employer must withhold 0.9% on wages >$200k).
  9. 401k limits: electiveDeferralLimit $24,500, catch-up 50+ $8,000, enhanced 60-63 $11,250 per SECURE 2.0, overall $72,000 / $80,000 / $83,250, compensation limit $360k. Source IRS retirement topics 2026.
  10. HSA limits: self-only $4,400, family $8,750, catch-up 55+ $1,000 per IRS Rev Proc 2025-19. Via payroll reduces FICA, outside payroll does not.
  11. State taxable income = stateTaxableWagesGross - state standard deduction - personal exemption (per Tax Foundation 2026 + state DOR).
  12. State income tax via data-driven file data/states-2026.js - 50 states + DC, system: none, flat, progressive, specialCases. Brackets from Tax Foundation 2026 as of Jan 1 2026, plus mid-year updates (GA HB 463 flat 4.99% retroactive). Confidence labeling: verified where official DOR cross-checked, else estimate.
  13. State payroll taxes: CA SDI 1.3% no cap, NY PFL 0.432% max $411.91, NJ TDI 0.19% FLI 0.23% up to $171,100, WA PFML 1.13% total employee ~0.71% + WA Cares 0.58% no cap, CO FAMLI 0.88% total 0.44% employee up to $184,500, CT PFML 0.5% up to $184,500, MA PFML 0.46% employee, RI TDI 1.1% up to $100k, OR Paid Leave 1% total 0.6% employee estimate, etc.
  14. Local tax: explicitly $0 + not modeled flag. Excluded: NYC, Yonkers, PA EIT/LST, Ohio municipal, Maryland county, MO KC/St Louis, Indiana county, Michigan cities, Kentucky/Alabama occupational, NY MCTMT. Disclosed.
  15. Net pay = gross - totalTaxes - totalDeductions (pretax + post-tax). Clamped 0 ≤ net ≤ gross. Per-period breakdown reconciles: sum per-period == annual via allocatePeriods rounding.
  16. Rounding: cents rounded only at display/breakdown, not mid-calc. All currency via Intl.NumberFormat USD, half-up. formatCurrency and formatPercent single source.
  17. Effective rate = totalTaxes / gross *100, take-home % = netAnnual / gross *100, deductions excluded from taxes.
  18. History/share: same result object used for share links, PNG export, localStorage history - no recomputation.

PA: 401k taxable per PA DOR. NJ, CA, AL: HSA non-conforming per FTB/NJ DOL.

State Conformity

  • 401k pretax allowed in all except PA (and PA local variations)
  • HSA pretax: not allowed in CA, NJ, AL
  • Cafeteria: allowed everywhere except where noted
  • Standard deduction: uses federal amounts where state conforms to federal taxable income (CO, IA, ID, etc.), else state-specific (GA $15k/$30k per HB 463, NC $12,750/$25,500, etc.)

Edge Cases

  • $0 income → net $0, all taxes $0, empty state message "Enter your salary..."
  • Deductions exceeding gross → clamped, warning displayed, net floored at 0
  • Negative → validation error, no calculation
  • Hourly non-default: totalHours = hoursPerWeek * weeksPerYear, hourly = annual / totalHours, no hardcoded 2080 when custom
  • Monthly/semimonthly: grossAnnual = monthly*12 / semimonthly*24
  • SS cap: capped notice displayed when wages > $184,500
  • Additional Medicare: separate liability vs withholding displayed
  • CA MHS 1% over $1M, MA surtax 4% over $1,083,150 (indexed) modeled as add-on
  • Per-period sum reconciliation via allocatePeriods

What is NOT modeled

  • Local/city/county taxes (NYC, Yonkers, etc.) → $0 + not modeled flag
  • Itemized deductions, credits (except W-4 dependent amount, standard deduction)
  • Self-employment, capital gains (except WA capital gains noted as excluded), AMT, etc.
  • Employer matching, state-specific credits
